## Today's Lesson

Today I'd like you to spend about an hour learning these concepts:

Business Questions

Learn the difference between:
- A business question
- A data question
- A technical question

For example:

**Business question:**
- Why did profit decrease?

**Data question:**
- Which products had the biggest profit decline?

**Technical question:**
- Which SQL query retrieves monthly profit?

Being able to distinguish these is an underrated skill.
