# Your First Assignment (Day 1) -- by Chatgpt

This is all about building the mindset of an analyst.

## Objective

Learn to ask better questions before touching the data.

Imagine you're hired by a supermarket.

Before seeing any dataset, write answers to these questions:

-What decisions might the supermarket owner need to make?
-What data would help answer those decisions?
-What KPIs (Key Performance Indicators) would you track?
-If you could build only one dashboard, what would it show and why?
-What recommendations might you expect to make based on the analysis?

There are no perfect answers here. I'm interested in how you think.
