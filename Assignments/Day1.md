That's possible...

But why?

Imagine this situation:

Product A sells only 5 units every month.

Should we stop stocking it? Maybe not. What if each sale earns ₦250,000 in profit?

One slow-selling item could still be worth keeping. That's why analysts need multiple metrics before making recommendations.
